Subarchy docs

Subarchy is in development and has no release. This page covers what works today, taken from the source at the time of writing. The design decisions are in the decision records.

01Try it

There is no published image. Build the ISO on Arch Linux. You need archiso, Go, Docker and sudo; the image lands in build/iso/.

git clone https://github.com/subculture-collective/subarchy.git && cd subarchy
make iso

The image carries a few packages that Subarchy rebuilds from pinned sources, among them the Limine packages, Neovim with its plugins and the keyring. On a fresh checkout they are not in build/repo yet, so the first make iso stops with a line that starts build.sh: not in build/repo: and lists them. Build the ones it lists in a clean container, then run make iso again:

packaging/aur/build.sh <package>...

CI does not rebuild them; it takes them from Subarchy's signed package registry (tools/ci/build-iso.sh).

Boot it in QEMU and check it over the serial console (needs qemu-base and edk2-ovmf):

make iso-test

Install from the newest ISO into a VM disk, then boot and check the result (also needs swtpm and imagemagick):

make install-test

The same through the guided installer with the guest's network off:

make install-test-offline

The live ISO is UEFI only and boots with systemd-boot and linux-zen.

02The installer

subarchy-setup starts by itself on the first console of the live ISO. On a serial console or over SSH, run it by hand.

It asks, in order, for a language, a keyboard layout, a Wi-Fi network (only when there is no wired route and a Wi-Fi card is present), a disk, a computer name, a user, a password, a disk passphrase and a time zone. Escape goes back one step on every screen.

  • The disk list shows what is on each disk. You can open a disk read-only before deciding.
  • The time zone opens on a guess. Online, that guess comes from ipapi.co or ipwho.is, whichever answers first within 4 seconds; the request sends them the network's public address. The page says where the guess came from.
  • A summary of every answer asks "Does this look right?". The erase question comes last and its default is no.
  • Skipping Wi-Fi is safe: the install runs from the package repository on the image.
  • While it installs, L shows or hides the end of the log. The full log is /var/log/subarchy-install.log.

The installer wipes the disk you choose.

03Unattended install

subarchy-install reads a KEY=value file and needs --yes, because it wipes DISK. The keys include:

DISK  HOSTNAME  USERNAME  USER_PASSWORD_FILE  LUKS_PASSPHRASE_FILE
TIMEZONE  LOCALE  KEYMAP  XKB_LAYOUT  XKB_VARIANT  SUBARCHY_REPO

The rest are listed in the header of install/subarchy-install.

06Updates and channels

subcult update

An update takes a snapshot, upgrades packages, runs migrations and cleans up, in that order.

A new system follows the stable channel: a dated Arch Linux Archive snapshot, so every machine on stable gets the same package set. To follow the Arch mirrors directly:

subcult channel set edge

07Theme, fonts, cursor

One palette file colours the shell, lock screen, terminal, Neovim, cursor, SDDM, Plymouth and Limine. The default theme is subcult-minimal. Themes are switched with Pult: pult apply applies one from its catalogue, pult tui browses and previews them, and pult doctor names the active one.

pult apply catppuccin-mocha

To go back to the default:

pult apply -profile /usr/share/subcult/default/theme/subarchy.toml

The login screen, boot splash and boot menu are system files, so they take the new palette only when you ask, with your password:

subcult theme apply-system

Fonts are three roles that GTK, Qt, the shell and the terminal all follow: monospace, sans-serif and serif. subcult font lists and installs fonts and can import ones you own.

The cursor is Subarchy's own, drawn in a palette colour. Choose the colour and size, or redraw it in the current palette after a theme change:

subcult cursor set --role lavender --size 24
subcult cursor apply

08Configuration

  • Your settings live under ~/.config/subcult/.
  • The palette Pult writes is ~/.config/subcult/theme/palette.json.
  • Bar layout: defaults in /usr/share/subcult/default/shell/bar.json, your overrides in ~/.config/subcult/shell/bar.json, merged key by key.
  • Hyprland: ~/.config/hypr/hyprland.lua, on top of the shipped defaults.
  • The app catalogue is default/apps.toml; subcult app validate checks it and any catalogue of your own.

09Snapshots and recovery

The root filesystem is btrfs with snapper. Limine shows a boot entry for each snapshot, so a bad update can be undone by booting the snapshot taken before it. subcult update takes that snapshot for you.

The installer also leaves a read-only factory-reset snapshot.

The lock screen is a separate program from the shell. If the shell crashes it restarts, and the session stays locked.
