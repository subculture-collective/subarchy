An Arch Linux desktop where the whole system answers to one command.

Subarchy runs Hyprland with its own shell, lock screen and theme. It is built from scratch by SUBCULT and borrows from Omarchy where that fits.

01

What it is

A desktop distribution on Arch Linux. You install it from a live ISO with a guided installer, and from then on you manage it with subcult: updates, themes, fonts, displays, hardware fixes.

The look is deliberate and cheap to run: no gaps, one-pixel borders, square corners, and no blur, shadows or animations. On battery the shell slows its own polling; on mains nothing is held back.

02

The desktop

The bar, notifications, on-screen display, polkit dialog, Alt-Tab switcher and launcher are one Quickshell program. Widgets update on events, not on a timer where they can avoid it.

  • workspaces
  • audio
  • network
  • bluetooth
  • battery
  • calendar
  • weather
  • media
  • tray
  • updates
  • clock
  • notifications
  • tailscale
  • downloads

Fourteen of the 27 widget folders in shell/widgets. Some panels and launcher features are still open on the roadmap.

One palette colours eight places: the shell, the lock screen, the terminal, Neovim, the cursor, the login screen, the boot splash and the boot menu. Pult applies it.

03

One command

Every tool is a subcult-* program on the path, and subcult finds them. sub is the short form. These lines come from the summaries in the source.

subcult update

Takes a snapshot, upgrades packages, runs migrations and cleans up.

subcult theme set subcult-minimal

Applies a theme. subcult theme list shows what is installed.

subcult channel set edge

Follows the Arch mirrors directly. A new system follows the stable channel, a dated Arch Linux Archive snapshot.

sudo subcult disk tpm enable

Unlocks the disk with the TPM instead of a typed passphrase.

subcult gpu run steam

Runs one app on the NVIDIA GPU of a hybrid laptop.

subcult commands

Lists every command.

04

Try it

There is no published image. To try Subarchy, build the ISO and install it into a virtual machine. On Arch Linux, with archiso, Go and Docker installed:

git clone https://github.com/subculture-collective/subarchy.git && cd subarchy
make iso

The first run stops and names the packages Subarchy rebuilds itself. Build them with packaging/aur/build.sh and the names it printed, then run make iso again. Details in the docs.

Or let the test harness build a VM disk, install into it and boot the result. This needs qemu-base, edk2-ovmf, swtpm and imagemagick:

make install-test

The installer wipes the disk you choose. It asks last and the default answer is no. Do not point it at a disk you need.

The installer asks for a language, keyboard layout, Wi-Fi network, disk, computer name, user, password, disk passphrase and time zone. It can install with no network, from the package repository on the image. More in the docs.
