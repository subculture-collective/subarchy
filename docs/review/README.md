# Review

Documents that need an owner decision. Each proposal states a default so the
review can be a yes/no pass.

| Document | Decisions |
|---|---|
| [ADR 0001](../decisions/0001-fork-strategy.md) | Fork, overlay or rebuild |
| [Plugin and add-on triage](triage.md) | What ships by default, as optional, or not at all |
| [Open questions](open-questions.md) | Name, licence, hosting, hardware targets, ISO |

## How to review

1. Read [ADR 0001](../decisions/0001-fork-strategy.md) and mark it accepted or
   rejected. Most other choices follow from it.
2. Go through [triage.md](triage.md) and change any **Proposed** value you
   disagree with. Leave the rest.
3. Answer what you can in [open-questions.md](open-questions.md). Unanswered
   items stay open; they do not block the inventory.
